# Calm Tasks

A small Angular todo application. Add, edit, complete, delete, and clear tasks; every change is saved in browser local storage, so your list remains after a refresh.

## Run locally

```powershell
cd "C:\Users\Diddy Party\Documents\Codex\2026-08-16\cr\outputs\todo-angular-app"
npm start
```

Then open `http://localhost:4200`.

## Storage

Tasks are stored under the browser local-storage key `calm-tasks.todos`. Clearing the browser's site data will remove them.
